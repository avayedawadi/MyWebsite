## Overview
This is an online robotics and block coding simulator built with Python and JavaScript. It is built off of the work that Dr. Sean Wilson has previously done as part of the on campus "Robotarium." The Robotarium is a swarm robotics lab where people all over the world can submit code to run on the lab. I built an online tool to reduce the barrier for entry.

## Purpose
This was built as part of funding from the Georgia State Legislature (which is also why the code cannot be freely published online). It is built with the purpose of expanding robotics access to kids in rural Georgia.

## Technical Details
This was built using HTML and JavaScript to render the site in the frontend. The backend uses Python and Matplotlib to run the simulation. I had to make alterations to the original simulator so that the video generated by the simulator could be passed back to the frontend frame by frame to be rendered for the user. The user can then take Python code generated by block code to run the simulation on the actual Robotarium.
